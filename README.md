# codealpha-hangman 
Hangman Game 

A simple word-guessing game built using Python as part of my CodeAlpha internship.

How to Play

- Run the Python program.
- Guess the word one letter at a time.
- Each incorrect guess reduces your remaining attempts.
- Guess the complete word before you run out of attempts to win!

Technologies Used

- Python
- Random module

What I Learned

- Using Python lists and strings
- Using loops and conditional statements
- Using "random.choice()"
- Building a simple interactive game
